Event Link Schema

    

        Reunicorn event links contain the event information as part of the fragment, i.e. the part beginning with the
        hash (#).
        The structure is as follows with each of the components indicated by curly braces being URL encoded.
    

    
https://reunicorn.app/events/#{name}~{start}~{end}~{location}~{url}~{longitude}~{latitude}~{UID}

    

        One downside of this schema is that the tilde character (~) used for separating fields is not allowed in any of
        the field values.
        The link generator above will replace "~" with "-" accordingly.
